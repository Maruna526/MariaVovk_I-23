\*\*Виконала:\*\* Вовк Марія

\### Мета роботи

Навчитися створювати віртуальне середовище Python, встановлювати й оновлювати зовнішні бібліотеки, працювати з `pip` і файлом `requirements.txt`.



\### Завдання 1. Віртуальне середовище

Створено віртуальне середовище `.venv`, перевірено шлях до Python і список установлених пакетів. Після вимкнення середовища Python із `.venv` зник зі списку шляхів.



\### Завдання 2. Бібліотека tabulate

Установлено бібліотеку `tabulate`. Програма `task2.py` читає `data/expenses.csv`, групує витрати за категоріями та виводить таблицю з кількістю записів і сумою. Загальна кількість записів — 12, загальна сума — 1425.00.



Після вимкнення `.venv` програма завершилася помилкою `ModuleNotFoundError`, оскільки `tabulate` не встановлено в системному Python.



\### Завдання 3. QR-код

За допомогою бібліотеки `qrcode` створено файл `contact.png` із контактними даними: ім’ям, групою та електронною адресою.



\### Завдання 4. Файл requirements.txt

Командою `pip freeze` сформовано файл `requirements.txt`. У папці `lab32\_copy` створено нове віртуальне середовище та встановлено залежності з цього файлу. Програма `task2.py` у копії працює правильно.



\### Завдання 5. Версії та видалення бібліотек

Установлено `tabulate==0.8.10`, перевірено версію, після чого бібліотеку оновлено до `0.10.0`. Бібліотеку `qrcode` тимчасово видалено, що спричинило очікувану помилку `ModuleNotFoundError`. Потім `qrcode` повторно встановлено, а `requirements.txt` оновлено.



\### Висновок

Під час практичної роботи навчилася створювати віртуальне середовище, встановлювати й оновлювати бібліотеки Python, використовувати `pip freeze` і `requirements.txt`, створювати QR-код та перевіряти залежності програм.
